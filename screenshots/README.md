# Project Screenshots

## Project Demonstrations

### 1. Graph Degree Calculator
A MATLAB App Designer application that computes vertex degrees, sorted degree sequences, and graph properties from an adjacency matrix.

![Graph Degree Calculator](screenshots/graph_to_degree.png)

### 2. Eulerian Circuit
Visualization of an Eulerian circuit in a graph with 20 vertices and 60 edges, using Hierholzer's algorithm.

![Eulerian Circuit](screenshots/euler-graph.png)

### 3. Havel-Hakimi Algorithm
Construction and visualization of a graph from a graphical degree sequence.

![Havel-Hakimi Algorithm](screenshots/havel_hakimi.png)

### 4. Hamiltonian Cycle
Visualization of a Hamiltonian cycle found using backtracking.

![Hamiltonian Cycle](screenshots/hamilton_graph.png)
